# Estructura del Empleo Formal en Ecuador

> **Proyecto en desarrollo**

## Estado del proyecto

**En desarrollo**

Este proyecto busca analizar la estructura y evolución del empleo formal en Ecuador utilizando datos oficiales del Instituto Nacional de Estadística y Censos (INEC).

Actualmente se encuentra en una etapa inicial de desarrollo, por lo que el contenido, metodología y análisis pueden cambiar conforme avance el proyecto.

## Objetivos principales

* Analizar la evolución del empleo formal en Ecuador.
* Explorar la distribución del empleo según diferentes características disponibles en los datos.
* Identificar patrones y relaciones relevantes dentro de la información.
* Aplicar herramientas de análisis estadístico y visualización de datos.
* Explorar diferentes métodos estadísticos y de modelamiento conforme avance el proyecto.

## Fuente de datos

Los datos utilizados provienen del Instituto Nacional de Estadística y Censos (INEC).
